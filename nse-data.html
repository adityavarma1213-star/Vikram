NSE Data — Static Mode

Static Mode — this page shows the verified NSE data already stored in the VIKRAM repository (coverage report below, and the full dataset in "Download Existing Dataset"). Live NSE acquisition is not available from this page.

VIKRAM's real acquisition mechanism (server/src/ingest.js) fetches Cash Market and Futures & Options end-of-day bhavcopy files directly from nsearchives.nseindia.com, one NSE trading day at a time, and requires a live, authenticated backend with database access (DATABASE_URL, AUTH_SECRET, ADMIN_EMAILS — see server/src/auth.js and server/src/adminAuth.js). It runs on a schedule server-side (see render.yaml's vikram-eod-ingestion cron job). That authentication and scheduled acquisition remain fully intact on the backend for future live use — this page simply doesn't call it, so it never prompts for credentials.
